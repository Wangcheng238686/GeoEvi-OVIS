## 1. 一句话目标（v2 历史说明）

给定遥感图像和任意类别文字（如 `airplane`），输出图中该类别每个独立实例的
mask。项目以 SAM3 的 text-only 实例发现为基础，再用同图候选、局部区域和场景的
关系来判断哪些结果可信、重复、冲突或可能不完整。

## 2. 为什么需要这条路线

SAM3 能从文字产生候选实例，但遥感图像中容易出现相似类别混淆、重复候选和大量
误检。P0 全量基线表明：候选召回足够进入后续研究（三集池化类均召回 0.5742，超过
GO 阈值 0.40），但误检占失败案例 87.6%。因此主问题是候选排序/消歧，而不是重新
训练一个分割器或单纯精修 mask。

## 3. 方法的直观流程

```text
图像 + 类别文字
  → SAM3 text-only 产生候选 mask
  → 建立“证据图”（候选、类别、局部区域、场景、unknown 的关系网络）
  → 用关系证据重新评估候选、合并重复、报告不完整风险
  → 输出最终实例结果
  → 可选：选择可靠候选作 visual exemplar，交给 SAM3 再分割
```

证据图不是新的分割器，不能凭上下文硬造实例。它只组织和使用已经存在的候选与
证据；text-only 是主结果，GT/self exemplar 是后续单列报告的增强模式。

## 4. 证据图中有什么

- 节点：查询类别、SAM3 候选实例、候选周边环带、全局场景、unknown；exemplar
  节点留给 P3。
- 文本—实例边：SAM3 分数与候选 crop 对类别文字的 CLIP 相似度。
- 同类支持边：候选外观相似或尺度接近。
- 相似类别竞争边：相近类别的候选若空间重叠，则记录竞争。
- 局部上下文边：候选周边的高置信类别结合训练集共现先验，作为软证据。
- 场景边：机场、港口、城市等图像级场景仅作为软分数。
- unknown 冲突边：低文本分且输给竞争类别的候选被标为不可靠。

所有初始阈值与权重均登记在 `sam3_ovis/docs/graph-thresholds.md`，不按结果回调。

### 阈值的依据与证据等级

当前 P1 是 training-free v0，阈值分三类，不能把它们都理解为“已经最优”。

| 类别 | 当前值举例 | 依据 | 证据等级 |
|---|---|---|---|
| 协议/评测继承 | 候选池原始 score ≥ 0.05；IoU 0.5；P0 GO 召回 ≥ 0.40 | P0 推理与评测预登记、COCO/实例匹配惯例、SCORE 已发表最弱基线参照 | 较强；固定以保持可比性 |
| 复用已有登记 | 高置信 `norm_text ≥ 0.5` | 复用 S3.2 局部上下文的高置信地板，避免为 S3.3 新增自由参数 | 中等；一致性选择，不是经调优最优值 |
| 启发式初值 | 文本/CLIP 权重各 0.5、竞争 top-K=5、文本相似 ≥0.50、竞争 IoU ≥0.30、尺度比 K=3、环带半径 0.25×sqrt(area) | 可解释的对称起点、几何邻近尺度和稀疏关系控制；在看 P1 指标前登记，防止事后调参 | 较弱；等待 S3.5 消融验证 |

共现先验本身来自 iSAID/SIOR 训练集统计，并使用拉普拉斯平滑；但其 floor=0.01
仍是避免零权边的工程性下限。当前没有用 SCORE 测试集标签搜索这些启发式参数，因而
P1 的结论不是“这些数字最优”，而是“在预先固定、可复现的合理起点下，证据图是否
值得继续”。若 S3.5 显示某项敏感，应把敏感性/消融结果写入报告；若需要改主定义，
应新建设计/登记版本，而不是回改历史阈值。

## 5. 完整性判断是什么

完整性不是 mask 边界质量，而是“该类别当前的候选集合是否看起来混乱或不完整”。

- ECR：高置信候选覆盖了全部候选区域的多少面积。
- URD：低置信候选中，有多少未被高置信候选解释为重复。
- CCR：有多少候选存在跨类竞争或同类重复冲突。
- R：三项症状的等权不完整风险分。

R 在后续只调制置信度和触发告警，不新增或删除实例。它对“完全没有候选”的漏检
没有感知能力，因此不能替代 P0 的召回评测。

run_ablation 的 IoU 表按候选次序存储、按字符串排序查询，会把部分重叠误读成零；
去竞争变体仅关闭消息权重，竞争边仍影响 CCR/R，与登记的去边定义不一致。
此外 bootstrap 排除了有 GT 但无预测的图，且其统计量为每图 AP50，不能解释为
COCO mAP 差值的置信区间。此前“必须先跑完三集再诊断”及对显著性的强断言需要
修正：先核对并修复实现、评测，再复算；概率或合并导致误检抬分仍是假设，尚未
被独立消融证实。工程冒烟通过不等于完整方法及科研结论已获验证。

- 不把 text-only 与 GT exemplar 结果混在同一主表。
- 上下文和场景永远是软证据，不能硬规则造目标。
- 当前 memory 指同图动态证据，不是跨图、视频或长期记忆。
- P1 先验证 training-free 图是否有价值；没有正信号就不应靠训练复杂化掩盖问题。
