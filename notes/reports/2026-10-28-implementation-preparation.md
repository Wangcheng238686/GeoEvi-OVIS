# 图 + SAM3 同图上下文记忆：实施准备交接

日期：2026-10-28。性质：研究准备与实施准入建议，不是已实现模型或新一版正式设计。

## 1. 已对齐的目标

用同一张遥感图像中的其他实例与环境证据，帮助当前实例的开放词汇识别与分割。
显式关系图负责组织原生 SAM3 memory 的访问，而不是仅在结果后面加一个重排图。
尽量保留 writer/reader，允许必要的小适配，并进行适当遥感主干微调。
训练可用源域完整实例标签；测试只有图像与类别文本。所有样本 memory 逐原图清空。
这些原则已明确，目前没有需要再次访谈才能开展接口验证的意图歧义。

尚未确定的是技术选择：环境节点怎么构造、图边如何训练、最终回接位置与预算。
下面给出受证据约束的验证顺序，不把候选写成负责人已批准的最终架构。

## 2. 本轮交付与证据

| 报告 | 主要结论 | 验证边界 |

## 3. 最小共同 pipeline（候选）

```text
图像 + 类别文本 → 可微 SAM3 首遍候选与视觉特征
                         ↓
           同图预测实例/环境记录 + 关系图
                         ↓
          图为目标选择完整栅格 memory 记录
                         ↓
       原生 writer / reader → 小残差桥接 → 概念分数/分割
                         ↓
               源域监督；切换原图清空 bank
```

首个接口实验使用同一画布、首遍建库后只读的两遍快照，不同时引入二维坐标改造、
跨窗循环更新和复杂图网络。它是成本与连通性探针，不是最终论文 pipeline 已冻结。
环境区域只由预测或图像构造，测试不得用 GT 帮助生成图、选择邻居或排除自身。

共同记录至少包含 `image_uid / canvas_uid / record_uid / source_candidate_uid /
role / predicted_quality / retrieval_key / memory / position / grid_shape`。
同图同画布的每条 memory 保持 `[B,64,H,W]`；reader 的 query 为 `[HW,B,256]`，
选 K 条记录拼为 `[KHW,B,64]`。图选择记录，不是直接塞任意 K 个 pooled 节点 token。
对象与环境的 mask/logits 分布须显式登记；不能把实例 ID 图作为 logits，也不能将
图质量分未经校准当作原生 object score。不同 neck 的特征不能因通道相同就互换。

生命周期必须由 `begin_image/end_image` 控制所有 bank。候选检索排除目标自身及
预测共指重复项；共指不确定性记录为误差来源，不用 GT 确认。checkpoint 不保存样本库。
完整 memory 仍带有整图视觉内容，不能宣称一条记录只包含该实例；需非 mask memory、
相同视觉特征不同 mask 的对照以辨别作用来源。

## 4. 第一技术关口：让记忆影响类别，而不只是 mask

默认 image builder 不建立 tracker；开启后，两套 neck 权重也不同。
只修改 tracker memory 不会自动改变文字条件 detector logits。

建议先验证 Q 桥接：完整画布经原生 reader 后，按固定首遍目标 mask 池化增量，
投影后加到对应 detector query，再重算原生概念 scoring。此时固定 boxes/masks
也是允许的诊断，但必须标为类别路径探针，不能声称修复零响应漏检。
同一物理对象跨文本的分数需显式对应，不能把不同文字下不同 query 的变化当作消歧。

随后检查 F 桥接：将 reader 增量经适配加入 detector 空间特征，再运行检测与分割。
它覆盖范围更完整，但多目标特异检索可能重复整图 reader/detector；需记录真实
实例数 N、检索数 K、显存和耗时，不能按图控制器参数少就认定轻量。
共享残差画布的冲突和 ROI 坐标适配均未验证，最终桥接暂不冻结。

空库残差必须为零，与同一微调基线数值等价。不要通过带 `inference_mode` 的
`Sam3Processor` 建训练图；走原生可微 forward/wrapper，核查权重 key 覆盖与优化器。
首遍 mask 是否 detach、视觉特征是否 detach 分开登记；不能无意断开 writer/主干。
零初始化 bridge 会使第一步上游梯度为零，须用非零诊断或第二步辨别真实断路。

## 5. 三条路线仍分开比较

| 路线 | 最小机制 | 必须排除的替代解释 |
|---|---|---|
| R1 关系选择 | 图决定读哪 K 条完整 memory | 与相同 K 的距离/相似度检索比较；仅 cosine top-K 创新不足 |
| R2 角色区分 | 固定集合与 K，区分自身/其他实例/环境的读写角色 | 角色打乱、等参数无角色对照；不能只是双 bank 改名 |
| R3 关系冲突准入 | 关系冲突决定记录是否准入 | 对象独立质量门控与同读取预算对照；不把置信度阈值称关系推理 |

三条不是递增堆模块。共同使用相同主干适配、训练数据、桥接和预算，再比较机制。
R3 第一版可采用硬记录准入，连续 attention bias 后置：原生 reader 当前拒绝
mask/padding/bias。给 value 乘权重不等于严格控制 attention 概率。
硬 top-K 与二值准入都不自动训练图评分器；若宣称边权可学习，必须另有经过梯度
验证的连续代理/辅助监督。规则图第一版可以训练 reader、bridge、主干，但要如实描述。

共同对照至少包含：同等微调无记忆、距离/相似度原生记忆、一次性上下文融合、
同预算关系图。另做同图随机邻居、错误上下文、删边/打乱边、角色打乱及空库干预。
数值变化只证明接通；图优于无图、正确上下文有益且错误上下文可抑制，才支持研究主张。

## 6. 实施准入顺序与交付要求

1. **G0 数据/环境/契约**：落实源图级 split 与 novel 类清单；核对训练依赖、包路径、
   checkpoint keys；完整尺寸 shape、空库/reset、记录顺序与图间隔离测试。
2. **G1 类别信息路径**：Q 小样本可微诊断，再检查 F；主干选定层、neck、writer、
   reader、bridge 的梯度、优化器覆盖及实际单步变化。实测 N/K 对显存与延迟的影响。
3. **G2 上下文作用空间**：独立源图 dev 上，与同等微调无记忆/无图记忆比较；
   固定预算做上下文干预，查对象串扰、共享视觉泄漏与类别分数饱和。
4. **G3 候选机制探针**：共同接口通过后，独立实施 R1/R2/R3，再收敛一路。
   不能把共同接口不可用造成的失败解释成所有图机制均无效。
5. **G4 独立确认**：冻结方案与超参后才用未暴露源图/novel 标签协议确认；
   按源图组重采样、重算全局 COCO 指标，报告多 seed 与成本。

不先设“提升 X AP 即成功”的经验阈值；根据匹配基线、开发集波动、成本预算登记
可检验判据，不能看最终测试结果后回填阈值。不能用 NWPU 跨数据集直接代表 novel：
其类别与 iSAID 大量重合，vehicle 还有父子类别问题；详见数据报告。

本次采样 4 张 24GB RTX3090 均被高占用，未启动 GPU 作业；官方训练入口所需
hydra-core/omegaconf/submitit 在当前环境缺失。主目录空间紧张，后续大文件应在
容量较充足的数据盘规划。状态是“准备报告完成、局部接口验证通过”，不是“可直接开训”。

CA-SAM2/GPRN 未确认完整许可证；阅读组织方式和独立实现可作为准备，若复制、分发
源码须先明确授权。SCORE/MPG 等许可证及具体来源见文献报告，不能一概视为可任意移植。

## 7. 与历史工作的关系及本轮边界

v3 空间惩罚已关账，v4 跨窗正框传播 S0 已停止；两者不是当前原生记忆方案。
其固定候选诊断不能外推为微调与可训练上下文无收益，也不能反向当成新方案证据。
SAM3 当前目录不是独立上游 git 仓库，项目 SHA 变化不构成上游版本升级证据。

本轮已完成获准的文献、源码、运行条件准备与 CPU 组件复核；未改模型代码、未安装
依赖、未训练、未复现第三方指标，也未把候选提升为正式新设计版本。
下一步建议范围为 G0/G1，共同接口和类别信息路径验证，不直接启动完整矩阵。
