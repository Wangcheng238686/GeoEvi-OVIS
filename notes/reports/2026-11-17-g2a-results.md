# G2a 结果：冻结主干下的记忆路径训练对照（2026-11-17）

> 协议 `2026-11-16-g2a-protocol.md`（判读标准 §4 先于结果登记）。
> 数据：`logs/g2a/train_summary_MX.json`（M/X 臂）+ `train_summary.json`
> （N 臂修复版）+ `/data/wangcheng/geoevi-g2a-cache`（30 图，train 18 /
> val 12，171/122 个 GT 匹配目标，base top-1 = 0.811）。
> 1500 步 × 3 种子 × 3 臂，AdamW 1e-4，val 每 250 步。

## 1. 主结果

| 臂 | s0 / s1 / s2（val top-1） | 相对 base | 逐目标配对（vs N 或 base） |
|---|---|---|---|
| base（无注入） | 0.811 | — | — |
| **N 零记忆可训** | **0.844 / 0.836 / 0.852** | **+2.5 ~ +4.1pt** | vs base：三种子全正，p=0.125/0.25/0.0625（未达 0.05） |
| M 真实 bank | 0.787 / 0.795 / 0.820 | −2.5 ~ +0.8pt | **vs N：−5.74 / −4.10 / −3.28pt（s0 p=0.039 显著负）** |
| X 异图 bank | 0.779 / 0.787 / 0.795 | −1.6 ~ −3.3pt | 一致损害；M−X = +0.8 ~ +2.5pt（M 一致优于 X） |

## 2. 判定（按登记判据树）

1. **"M−N ≥ +3pt 且 p<0.05 且方向一致"未达——方向完全相反。** 真实
   bank 记忆注入在三个种子上一致劣于零记忆对照（每种子 −3.3 ~ −5.7pt，
   其中 s0 达统计显著负）。**记忆内容假设在 G2a 设置下被否定。**
2. **触发"N 本身超基线"分支**：零记忆可训路径带来一致 +2.5~+4.1pt
   （三种子同向、p 0.06–0.25 未确认）。按登记，这是**通用可训容量效应**
   （reader 作特征变换器 + bridge 校准 query），与记忆无关，**不得归因
   记忆/图**；且 n=122（绝对量 3–5 个目标），未过显著性，只作方向记录。
3. M>X 一致：bank 来源正确性有影响，但两者都不如零 bank——正确来源
   的记忆仍不如没有记忆。

## 3. 解释（登记为假设，非结论）

M<N 且 X 最差的结构指向 G1 §2.2 已登记的 **neck 失配**嫌疑：writer/
reader 预训练于 tracker neck 分布，我们喂 detector FPN 特征——真实记录
携带的失配噪声大于其信息量，训练 1500 步无法克服；零库路径无此噪声故
训练干净。若记忆路线继续，**G2b 的第一优先级是修 writer 输入分布
（neck 适配或输入归一化）后重测 M vs N**；否则按预注册止损。

## 4. 执行 trail（全记录）

- 缓存段 1 个真 bug：`flatten(2)` 对 3-D 张量无操作，canvas 被存成第 0
  通道空间平面 (72,72)——训练烟雾拦截，修复后 30 图全部重生成并断言
  [5184,256]。
- 训练段烟雾修 3 处：bank mask numpy→torch、DPS 需 4 维输入、CPU/CUDA
  张量混栈；另有 1 次误删 `class Arm:` 的编辑事故（编译期修复，未进运行）。
- **N 臂实现缺陷与修复（本轮最重要 trail）**：原 N 臂 Δ=real−null 在零
  bank 下恒为零 → N 沦为空操作（首轮 3 种子 0 翻转是构造使然，非对照
  结果）。判定该对照无效后，在 M/X 结果不受影响的前提下修复 N 臂
  （注入 `reader(零bank)` 输出本身：同模块可训、同预算、无记忆内容）
  并仅重跑 N 臂。**若未发现此缺陷，M−N=−1.09pt 会被误读为"记忆轻微
  无害"；修复后真实差距是 −3.3~−5.7pt，结论性质改变。**
- 资源：全程 GPU2 共享卡（邻任务 17.1GB 稳态），峰值 ~6.1GB 未影响
  邻任务；M/X 全量 1.8h + N 重跑 36min。

## 5. 对项目的含义

- v1/v3/v4 之后，记忆家族的第四个预注册否定结果（本轮：G2a 设置下的
  writer-encoded 记忆内容）。与前三次一致的模式：机制叙事有直觉吸引
  力，但预注册对照下信号不成立或为负。
- 诚实登记的**正向副产品**：冻结 SAM3 + 7.4M 可训小路径即可稳定改善
  val top-1 约 +3pt（未确认显著性）——这是"廉价适配器"性质的效果，
  可作为独立后续（与记忆主张解耦），也可以并入 G2b 基线。
- 方向决策留给负责人：A）G2b 修 neck 失配后重测记忆（预算中等，有
  明确嫌疑链）；B）记忆路线止损，转投"冻结基座 + 轻量可训适配器"或
  论文写作（含四条预注册止损 trail 与本副产品）。
