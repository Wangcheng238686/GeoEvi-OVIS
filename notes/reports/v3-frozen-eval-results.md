## 3. 判定（按预注册判据树）

1. **B2 ≤ B1 成立**（逐图均值负、CI 含 0）→ **停止相对惩罚机制**。
   开发集的 B2−B1=+0.28 pt 在全局 mAP 点估计上复现（0.2208−0.2180），
   但不显著且逐图配对统计为负——不能作为方法主张。
2. **B3 ≥ B2 复现**（全局 mAP 再高 0.64 pt，逐图差 CI 含 0 但方向不为负）
   → **空间图主张正式关闭**；与开发集审计结论一致。
3. 任何变体对 B1 的增量 CI 均含 0 → **不进入 T3**。
4. 诚实备注：B3−B1 的全局 mAP 点估计 +0.92 pt 是全表最大增量，但在
   n=146 的配对检验下不显著；按预注册规则不追加样本、不作主张。
   v3 的最终定位：**负结果/中性结果**——机制信号（T1 的 143:1 压错/误伤
   不对称）存在，但转化为数据集级 mAP 收益不可确认。
