## 1. 门设计（分数级模拟，无架构训练）

在 100 图缓存（25 组：train 54 / val 46 图）上，对**全候选集**
（pool floor 0.05 的全部预测，含 FP，15 类）做 COCO segm mAP 对照：

| 臂 | 分数 | 角色 |
|---|---|---|
| A0 | s_DPS | 基线 |
| **A2** | s_DPS + α·R_ctx（高置信上下文 ≥0.3 的 RemoteCLIP 文本逻辑均值） | **架构一致臂**（裁定①下的名义设计） |
| A3 | s_DPS + α·R_uni（自身+上下文 crop 统一编码均值） | 写路径编码器统一性检验 |
| A1 | s_DPS + α·R_self（自身 crop 单列） | **诊断上限**（裁定①禁其单独成臂，仅作 oracle 参考，不进结论） |
| A4 | s_DPS + α·R_foreign（异图上下文） | 来源正确性对照（不得优于 A2） |

- α ∈ 网格，**仅 train 组选择**；val 组评估。
- 逐候选证据：候选自身 crop 与其图内高置信上下文（IoU<0.5 排除自身
  重复）的 RemoteCLIP 文本逻辑；异图对照取固定 seed 异图。
- 新增缓存：全候选集（mask RLE/box/score/类）+ 逐候选证据向量
  （`/data/wangcheng/geoevi-g2a-cache/cands/`）。
- 统计：val 组 COCO segm mAP；**源图组配对 bootstrap**（10,000 次）
  报 A2−A0、A3−A0、A2−A4 的 95% CI。

## 2. 判定（预登记）

- **过门**：A2−A0 ≥ **+1.0 mAP pt** 且 bootstrap CI 不含 0；A2 > A4。
- A2 过门而 A3 ≈ A2：统一编码成立（self 作记录无害）；
  A3 > A2 显著：登记"self 编码贡献突出"，架构上仍按统一写入处理
  （裁定①），差异作为消融解释。
- A2 不过门（<+1pt 或 CI 含 0）：**方向 2 在 mAP 口径止损**——与 v3
  同命（目标级有信号、mAP 不传导），如实归档，不进入架构训练。
- A1（诊断）与 A4 的读数不改变上述主判定的方向。

## 3. 边界

- 分数级融合是架构的**信息论代理**：真实通路（writer/reader/bridge）
  有表达损失与训练动态，过门是必要非充分条件；
- GT 不进入任何证据构造；上下文只用预测（≥0.3 置信）；
- mAP 全分母（含 FP/漏检），与 v3 的 COCO 口径一致可横比。

## 4. 修订（2026-11-21，结果产生前）：增设 A5 消融臂

依据查重报告 `2026-11-21-g3b-prior-art.md` 的建议：SCORE 是中高威胁
最近邻（共享动机与编码器，机制三处正交）。增设：

| 臂 | 分数 | 角色 |
|---|---|---|
| A5 | s + α·R_self^dilated（自身 mask 膨胀区域 crop 的文本逻辑，margin 形式） | **SCORE 式直注的分数级模拟**（强制消融） |

判读补充：A2 必须与 A5 一起报告——若 A2 ≤ A5，图筛选相对几何膨胀无
独立价值，G3b 的图贡献主张不成立（可退化为 SCORE 变体）；A5 的膨胀
尺度取固定大边距（0.5），登记为模拟而非复现。
