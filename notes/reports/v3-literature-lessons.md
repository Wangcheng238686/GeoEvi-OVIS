# v3 文献复核：当前失败给下一步留下什么问题

日期：2026-09-05。入口：`papers/KB/00-INDEX.md`。本次重点核对 SCORE、
DAM4SAM、RMem、SAM3、FSS-SAM3、ELFSS-AR 的本地原文，不代表重新审计全部 33 篇。
以下是研究建议，不是已经实施的 v3 改动，也不是新实验结果。

## 1. 当前事实边界

`sam3_ovis/logs/ablation/eval_NWPU_fixed.json`：A1=0.2475、A2=0.1551，
去竞争=0.1831、去上下文=0.1566、去场景=0.1602、去风险=0.1696。
A2 比 A1 低 9.24 个 mAP 点；去竞争回升 2.80 点，去风险回升 1.45 点。
类均召回由 0.7627 降为 0.7424，不应称为“召回无损”。

当前 runner 已逐图清空特征缓存、统一 IoU 键排序，并移除去竞争变体的相关边。
旧版 0.1330 结果不能与修复结果混用。评测仍以每图 AP 均值差做 bootstrap，
不是重采样后重新计算全数据集 COCO mAP 的置信区间。

完整图效果差已成立；“概率或是主害”“支持边形成回音室”仍须固定候选、
固定其余算子的独立消融及 TP/FP 分数轨迹确认。去竞争改善不能独立证明支持边有害。
误检占失败账本 87.6% 也不等于 87.6% 都是跨类别混淆。

## 2. 最直接的启发：先验证证据能否判别，再研究如何传播

### SCORE：场景编码器和实例分类器不是同一职责

原文 Table 6 / “Open-Vocabulary Classification” 将场景 VLM 与 OV 分类 VLM
分开比较：在其训练与评测设置中，通用 CLIP 用于分类优于对应遥感 CLIP；
RemoteCLIP 则在场景分支有价值。这直接挑战 v3 默认 RemoteCLIP crop 足以消歧
的前提，但不能外推为通用 CLIP 必然在我们的冻结 SAM3 管线上获胜。

建议在源域开发集的固定候选上比较通用 CLIP 与 RemoteCLIP：相同文字模板、
相同图像区域、相同标注配对，测正确类相对混淆类的 margin、混淆对排序准确率，
并测对背景误检的辨别能力。仅看图像分类 top-1 或相似度绝对值不够。

原文还发现直接 addition/concatenation 融入全局上下文会退化，其解释是两套
嵌入空间不对齐。我们的同模型分数融合并非同一种操作，不能直接归因于这一机制；
可迁移的是“融合需要单独验证”，不是“加 attention 就能解决”。

来源：`papers/_extract/score_full.txt`，Table 5/6 及对应讨论。

### DAM4SAM：发现竞争不代表竞争证据可信

原文消融发现，仅在检测到 distractor 时更新记忆可能放大分割错误；同时要求
可靠跟踪和检测到 distractor 才有明显收益。这是视频跟踪的结果，不是静态图证明。

对 v3 的提醒：同位置出现另一个类别的候选，只说明存在另一种解释，不能证明
另一类为真。即使采用最大竞争 margin 和乘性降分，也可能由错误竞争者压低 TP。
优先报告每类 TP 被错误降分比例、错类 FP 被正确降分比例，以及证据缺失/不确定
时保持原分的比例。不要把“只降分”误写为“不会伤害”。

来源：`papers/extracted/DAM4SAM.txt`，DRM 更新规则消融。

### RMem：更多证据可能更差，但需在我们的算子上验证

原文通过受控实验展示冗余记忆稀释注意力。我们的图包含手定消息与概率或，
并非其注意力读出，因此它支持“检验冗余敏感性”，不证明当前失败的因果机制。

诊断可固定同一候选集合，仅复制/去重图中的证据表示，检查候选分数是否无理由
上涨；另比较固定代表 mask 下的原始分、max 聚合与概率或，分离合并几何和分数效应。
这些是定位旧版失败的可选诊断，不意味着要恢复完整图或采用论文的 K=8。

来源：`papers/extracted/RMem.txt`，memory deciphering 实验。

### SAM3：先区分概念不在场与实例错配

原文 Presence Token 将概念是否在场与候选是否匹配分解，最终分数已经相乘。
项目 API 笔记也确认 scores 含 presence 门控，不应把同一 presence 再乘一次
并当作新的独立证据。

开发集失败应至少区分：背景/不存在概念、定位到目标但类别错、同类重复、mask
定位质量不足。v3 的局部跨类比较主要针对第二类，无法保证解决另外三类。
GT 仅用于开发诊断，不作为推理输入；分类口径要登记匹配 IoU、优先级与重复处理。
只有第二类占比及可纠正空间足够，局部消歧才值得作为主线。

来源：`papers/_extract/sam3_full.txt`，Presence Token；
`sam3_ovis/docs/sam3-api-notes.md` 的 scores 定义。

### FSS-SAM3 / ELFSS-AR：不要把异任务结论升级为项目红线

FSS-SAM3 的负提示退化发生在其 few-shot 拼画布实验中，不能证明所有 SAM3
负提示都失败，更不能证明图上软惩罚必然安全。ELFSS-AR 使用 few-shot 支持信息，
不能直接把支持原型移植为 text-only 推理；w_ctx=0.01 的小系数也不独立证明
上下文贡献可忽略，须看各项量纲、分布及消融。

同理，KB 所称“mask pooling 必须”应降为可验证的表示选择：bbox crop、掩码
区域表示、保留少量上下文各有可能胜出。SCORE 的区域上下文不是单独背景环带。
能量优化的稳定性也不等于候选可靠性只许上升，误检恰恰需要降分。

来源：`papers/_extract/FSS-SAM3.txt` 摘要及负提示讨论；
`papers/_extract/ELFSS-AR.txt` 实体打分公式、支持信息与上下文定义。

## 3. 建议的最小决策顺序

1. **错因空间**：在源域分组开发集统计四类失败，估计局部跨类消歧能覆盖多少问题。
2. **证据信号**：先做同 crop 的正确类/竞争类判别审计；用有限、预先登记的
   编码器与区域表示比较确认其有效性，不展开无限特征搜索。
3. **最小干预**：信号成立后再做 v3 B0/B1/B2/B3，固定候选与 mask，检验
   相对证据是否比独立分数多提供信息，尤其检查 TP 伤害与随机竞争对照。

若第一步空间不足，不能靠调整 lambda 解决选错问题；若第二步没有信号，
不能靠消息传递创造语义能力；若前两步成立而第三步失败，才重点审查融合与校准。
选择只在开发集进行，NWPU 已暴露，不能再用来挑编码器然后宣称独立验证。
本次不修改 v3 已登记公式、不启动实验；需要采用的建议应在实现前更新设计登记。
