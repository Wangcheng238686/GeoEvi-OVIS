# R1 协议 v2（重登记）：源域微调 SAM3——定位质量 + 域适配（2026-11-22）

> 取代 R1 首版动机（"找回缺失检测"——审计②已证候选大多存在于低分带，
> 该动机不成立）。新基线 = G5a COMBO（空格 prompt + floor 0.01 +
> 1344；mAP 0.2700 / center 召回 95.3% / same-class 31.8% / FP 290/图，
> 117 val 组图）。路由维持：基座动力学型；冻结诊断 = G4a+G4b+G5a 三连
> 审计。资源：共享卡 ~8G 余量/卡或空闲窗口；配方依据外部调研
> （`2026-11-22-external-benchmark-survey.md`）。

## 1. 预注册四要素

- **主指标**：val 组全集（117 图）NMS 池 segm mAP。
- **伴随指标（≥2 维）**：same-class 召回（31.8% 基线——COMBO 的最大
  代价项）、FP/图（290 基线）、any-class center 召回（95.3% 基线，
  监控不回归）。
- **选择口径**：last checkpoint（无 best 挑选；轨迹每 500 步落盘仅作
  诊断）。
- **显著性**：与 COMBO 基线的逐图配对 bootstrap（2000 次，CI95）。
- **判定门**：
  - **GO**：mAP ≥ 0.39（外部锚 ×1.45）且 CI 下界 > 0，same-class
    召回 ≥ 45%，FP/图不升破 350；
  - **PARTIAL**：mAP 0.30–0.39 且 CI 不含 0 → 配方调参一次的资格
    （lr/解冻范围/增广），不另设新门；
  - **NO-GO**：mAP < 0.30 或 CI 含 0 → 微调线止损，剩余路线转
    分数校准/FP 治理。
- 首轮单 seed；过门后补 2 seed 验证稳定性（均值落判）。

## 2. 配方（外部调研三要素 + 已有脚手架）

- 训练入口：官方 trainer（r1_isaid.yaml 已就绪，包装器已过 RoPE/
  融合核两坑），数据 = G0 train 1,024 组 JSON（已生成）。
- **prompt 一律空格式**（与基线一致，消除 L1 混淆）。
- 微调范围（首轮）：LoRA r=8 于 vision backbone 注意力投影 + 概念
  transformer（1.08% 参数，外部单卡验证过）；AdamW 3e-5~5e-5、
  25–40 epoch 等效（target_epoch_size 1500 × 30）；**独立 p=0.5 光度
  增广**（GOOSE 单项最大增益）。
- 分割损失本轮开启与否：首轮关（box+presence，与基线候选生成一致；
  seg 头冻结），mask 质量线后置。
- 评估：G5a eval 管线直用（`--eval-only` + 新臂目录）。

## 3. 边界

- floor 0.01 下的 FP 洪峰是排序问题：微调若推高 FP/图，GO 门已含
  FP ≤ 350 的护栏；
- novel 侧（SIOR 清单）评估在 GO 后的确认阶段执行（首轮 seen-only）；
- 全部 ckpt/日志在数据盘 `/data/wangcheng/geoevi-r1/`，EXP-ID 于
  全量启动 commit 发放。

## 5. 实施偏离登记（2026-11-21，全量启动前，烟雾验证所得）

1. **LoRA 覆盖 = 视觉主干 50 个注意力投影（1.12M 参数）**；概念
   transformer 的注意力全部为 nn.MultiheadAttention（36 个）——替换其
   内部 Linear 要么崩溃、要么被 MHA 快速路径静默绕过（烟雾实测
   AttributeError 拦截），故排除。协议 §2 的"概念 transformer"目标在
   run-1 落空，登记为已知偏离；若 PARTIAL 进入配方调参轮，可加 MHA
   输出空间 LoRA 包装再试。
2. `target_epoch_size` 为死旋钮（trainer 不读）；epoch=全数据集一遍。
   30 epoch 目标改写为 **max_epochs=5**（53.9k 迭代 = 36 epoch 等效，
   落在协议 25–40 区间，~18.7h）。
3. 评估侧 seg head 从基座保持（训练未建），strict=False 加载并以
   断言限定缺失键仅 segmentation_head.*。
4. 烟雾验证：损失下行（229→227 均值线，瞬时 69~628）、显存 9.0GB、
   ckpt 落盘并可经评估路径回载。
