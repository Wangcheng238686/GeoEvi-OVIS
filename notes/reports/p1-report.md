## 3. 失败诊断（机制级，已在数据上验证）

1. **排序被破坏而召回无损**：A2 召回 0.742/0.781 vs A1 的 0.763/0.794
   （−2 个点内），mAP 却掉 9.2 个点——图的全部干预（支持增益、合并增强、
   风险调制）都在重排，且重排方向系统性有害。
2. **FP 回音室**（主害）：支持边对"外观相似/尺度接近"的候选互相增益；
   P0 失败账本显示误检恰好成群且相似（32 万条，占失败 87.6%）。同类 FP 群
   在两轮消息传递中互相抬轿；竞争惩罚（α_c=0.30）只覆盖跨类重叠，对同类
   FP 群无能为力。消融佐证：−竞争挽回最多（+2.8），但 A3−竞争仍低于 A1
   ——支持臂的回音室依旧存在。
3. **分数压缩 + 全局风险调制**：`final = rel×(1−0.5R)` 且 R 在候选密集图
   常年 ≥0.5——含真目标的硬图（候选多→URD/CCR 高）被整体降权，其真检测
   在全局排序中被干净图的 FP 压过。修复版里去掉风险调制仍只回到 0.17，
   说明压缩伤害在 rel 本身的量程，不止调制项。
4. **概率或合并无差别增强**：`1−Π(1−rel_i)` 使多成员簇得分趋高，而成员多
   恰恰是 FP 群的特征（demo 实证：gtIoU=0 的簇 merged=0.98）。

## 4. 同时成立的正发现（写入论文的资产）

1. **候选池本身就是收益**：A1（全池 0.05 + 归一打分 + 标准NMS）比 A0
   （官方 0.5 阈值）高 +5.6 mAP、召回 +0.27——SAM3 的低分响应里确实有
   真实例，官方阈值在丢弃它们。"池扩展"应作为所有后续方法的共同起点。
2. **召回与排序可分离**：图的干预保住了召回却毁掉排序——说明"用上下文
   关系做实例级消歧"的方向并没有被证伪，被证伪的是当前的手定消息传递
   形式（加性增益/惩罚 + 或合并 + 全局调制）。
3. P0 的失败结构判断不变：误检排序仍是主矛盾，需要的是**判别式**的排序
   信号（如跨类竞争的乘性压制、按质量门控的支持），而不是对称的相互增益。

## 5. 决定与下一步（触发设计迭代）

1. **P1 停线**；P2（可学习化）不启动——在 training-free 图为负的前提下
   训练图模块违背 §12.4 纪律；P3（exemplar）依赖 M2，同样冻结。
2. **触发 design-v3 讨论**（按 notes/README.md 迭代规则），输入即本报告
   §3/§4。候选方向（供设计层评估，非结论）：
   - 支持边质量门控：增益只来自高置信成员，且按成员数收益递减；
   - 竞争改乘性压制（比值型），取代加性惩罚；
   - 合并去增强化：代表分 = max(rel) 或成员数门控的温和提升；
   - 风险调制改图内自适应或仅作告警输出（不进排序）；
   - 重新审视贡献点表述：若排序增益不可得，图的独立价值或应在
     完整性/不确定性输出与 exemplar 选择（P3）上主张。
3. 复跑 P1 前须新登记版本（阈值/公式/合并规则一并冻结），矩阵仍按 §12
   三测试集执行。
4. 用户侧遗留不变：NWPU-Refer 已入库；HF 官方访问可放弃（权重已校验）。
