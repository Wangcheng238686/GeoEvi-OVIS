# 同图关系上下文记忆：三条候选探针路线

日期：2026-10-25。状态：研究草案；核心需求已确认，具体模型尚未批准实现。
约束以 `../decisions-2026-10.md` 为准。查重见同目录
`2026-10-25-sam3-relational-memory-prior-art.md`。

## 1. 共同目标与监督

源域完整实例标注用于微调 SAM3 与关系记忆组件；测试仅图像与类别文本，无人工
exemplar、目标 GT 或跨测试图样本库。novel 指相对本项目适配标签未见，不保证相对
基础模型预训练未见。图关系从预测 mask、位置与连续视觉/文本表示构建，不以训练
类别编号限定读写规则，不把“船只能在水里”等固定共现表当真值。

三条路线都研究其他实例与环境如何帮助当前目标的类别理解。共享同图观察、原生
memory 编码/读取与概念 detector 回接；机制变化只落在图如何组织记忆上。

context list 在每张图内初始化；texture list 通过外部参数传入，生命周期不能直接

## 3. 共同骨架（候选实现，不是已完成能力）

1. 对同图先做一遍文字概念分割，取得候选 mask、连续特征与分数。首轮全部完成后
   构建只读记忆快照，训练与推理保持相同的预测建库流程。
2. 实例观察节点存预测 mask 和视觉特征；环境节点先用几何环带/局部区域表示，
   不要求另训水体、道路或港口分割器。具名环境标签属于后续可选扩展。
3. 用原生 memory 编码器保存实例/区域证据，通过图选出的记录和原生 reader 条件化
   当前特征。当前候选自身输出不得充当独立外部上下文证据。
4. 用共享的小型残差投影把读取后的特征接回概念 detector，使记忆能影响类别分数；
   mask refinement 可同步测，但不能用 mask 改善冒充类别消歧。
5. 第二遍输出不再写回第一轮快照，初版避免递归级联。需要另设无缓存的一次性
   上下文 attention 对照，验证显式记忆编码、缓存复用和访问规则是否必要。

第一轮可在同一图像特征画布上编码多个 mask/环境区域，降低跨 tile 坐标适配干扰。
这不保证保留足够小目标细节；输入分辨率与候选召回必须独立检查。若改用 crop/tile
记忆，必须明确其局部/全局坐标和 reader 位置编码，不能只把时间 slot 换成二维坐标。

## 4. 三条路线

| 路线 | 图改变哪里 | 核心假设 | 主要失败风险 |
|---|---|---|---|
| R1 关系选择读取 | 用实例—环境边为 query 选择有限 memory 记录 | 有效上下文取决于与当前实例的关系，单纯距离/相似度不足 | 图与普通 top-K 选到同样信息，收益很小 |
| R2 角色区分读取 | 同一 reader 内加入轻量角色/关系嵌入或输入投影 | 当前对象身份、其他对象和环境应以不同角色读取，可减少串实例 | 看似角色有效，实际只是新增参数或额外训练 |
| R3 冲突门控写读 | 利用关系一致性控制记录准入或读取权重 | 图能识别单对象分数未反映的错类/环境冲突，减少污染 | 共现偏置压制罕见真目标，错误邻居形成相互确认 |

R1 首轮只改变选择，不叠加 R2/R3；R2 使用相同候选 memory 集合检查角色编码本身；
R3 使用相同 reader 和候选集合检查关系门控本身。三者相互独立，不先做 R1+R2+R3
大模型。它们是后续并行探针方向，不是本轮已验证的贡献。

R1 建议优先落地，因为最贴近 CA-SAM2 的可复用代码。R2 的潜在机制差异较清楚，但
必须先验证把其他实例放入 reader 是否发生身份混淆。R3 对应既有错误污染问题，但
需特别防止重复 v2 中用未经校准的关系手工改分。

## 5. 统一对照与逐步准入

- B：同样遥感主干适配的 SAM3，无新增 memory。
- U：相同主干与回接 adapter，使用 CA-SAM2 式距离/相似度检索，无图。
- A：相同预算的一次性同图上下文 attention，检查缓存和 memory 表示的必要性。
- R1/R2/R3：各自只有一种图干预，使用匹配的参数/token/训练与推理预算。

第一道门是接口与信息路径：reader 可微、reset 正确、空 memory 退化可验证；替换
memory 后概念分数是否受影响，影响是否仅来自尺度或归一化改变。

第二道门是源域小样本作用空间：先用实际预测上下文评估类别信号，再用 GT 作纯离线
oracle 定位上限。oracle 是诊断，不可作为模型输入或公平主结果。若上下文有效却
无图 top-K 已取得同等效果，记忆路线可保留但该图机制不升级。

第三道门才是同预算短训练并行。所有路线从同一个源域适配 checkpoint 出发，使用
固定源图级 split、相同 optimizer step/样本数。另报告真实 GPU 时间、参数和 token
数，避免把“训练步相同”误认为所有成本完全相同。预算在执行前单独登记。

开发集只用于选择。选择后冻结，在未用于选参的源图组与 novel 类确认集评估；不
从多路线测试最优中挑结论。记录所有负结果，以原图为配对统计单位。

## 6. 选择指标与图的必要性

主指标：实例 segm mAP 与 seen/novel 分项；诊断拆分错类、背景误检、漏检、mask
形状与实例串扰。除总体 AP 外，检查目标内特征相似但上下文不同的困难子集；子集
定义在开发数据上冻结，不能挑成功案例。

每条图路线都须检查正确边、无边、匹配度数的随机边、错误环境与正确环境。模型
须保留读取对象、边、权重与写入来源日志；“换边不影响输出”或“打乱边不降性能”
应削弱图贡献主张。因果干预同时报告副作用，不能只展示支持预期的例子。

最有希望路线按确认数据上的稳定增益、novel 保留、图的独立增量及计算成本综合
选择；尚未冻结绝对 mAP 门槛。若三条路线均不优于匹配的无图对照，就报告当前
关系机制失败，回查动机或重定机制，不能把固定约束解释为保证图一定有效。
