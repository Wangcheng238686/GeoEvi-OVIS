# v3 冻结参数独立验证计划（T2 收尾）

> 日期：2026-10-25。脚本：`sam3_ovis/graph/run_v3_frozen_eval.py`。
> 依据：2026-09-28 第二轮审计（explainer）——"下一步只做一次冻结参数的独立
> 源图验证"，本计划在任何验证结果产生前登记。

## 1. 冻结配置（不得更改）

- 参数：β=0.5、δ=0、λ=2（dev 上 B2 最优网格点，2026-09-28 登记）。
- 打分唯一入口：`graph.scoring_v3.score_candidates`（含 B3 的
  `z_rival_max_nospatial`）；禁止任何手写公式（T2 两轮失效的根因）。
- B3 rival 集合 = 同图其他**预测类别**（预测候选类并集 − 自身类，不做空间
  限制）；B2 rival 集合 = 空间重叠（IoU≥0.5）候选的类别。两者均在 cache
  阶段落盘为 `rival_z_spatial` / `rival_z_pred`，score 阶段零歧义。

## 2. 验证集

- 数据：iSAID train（与 dev 同分布同词表）。
- 排除：`logs/t2_cache/manifest.json` 登记的 15 个 dev 源图组。
- 抽样：held-out 组中以 seed=20260907 取 10 组、上限 200 图；
  零 GT 图不进分母（组级过滤，登记于脚本 docstring）。
- 唯一性：本验证只运行一次；结果无论正负都作为 v3 最终口径归档。

## 3. 评估口径

- 主指标：COCO segm mAP@[.50:.95] + AP50（真实 mask RLE）。
- 显著性：逐图 AP@[.50:.95]（maxDets=100，全部面积档，零预测图计 0），
  图为单位的配对 bootstrap（10,000 次重采样，seed 同 20260907），
  报告 B2−B1、B2−B3、B3−B1、B1−B0、B2−B0 的均值差、95% CI 与 P(>0)。

## 4. 判据树（预注册）

| 结果 | 决定 |
|---|---|
| B2 ≤ B1（CI 含 0 或均值为负） | 停止相对惩罚机制，v3 整体关账 |
| B2 > B1 但 B3 ≥ B2 | 放弃空间图主张；至多保留"同图类别对比重排"作为简单后处理，单列报告 |
| B2 同时 > B1 且 > B3（CI 均不含 0） | 才有资格进入 T3 测试集确认 |

dev 证据（B3 0.2655 > B2 0.2648，B2−B1=+0.28 点）预示第二行是大概率结局；
本验证的作用是把它变成未暴露数据上的可信结论。

## 5. 成本与运行

- cache 阶段（GPU 单卡）：~200 图 × 4–5 s/图 ≈ 15–20 min（dev 237 图
  实测口径）；逐图 done ledger，可断点续跑。
- score 阶段（CPU）：<5 min（含逐图 AP）。
- 运行命令见脚本 docstring；产物 `logs/v3_frozen_eval/{manifest.json,
  candidates.jsonl, done_images.jsonl, frozen_results.json}`。
