## 设计—实施对应规则

- 每版 `design-vX.Y.md` 对应一份 `implementation-vX.Y.md`；设计迭代后实施文档按新版本重建，不跨版本续用。
- 设计文档只定科学边界（做什么、为什么）；实施文档只定执行步骤（怎么做、判据、产出）。
- 冲突时以设计文档为准；实施中确需突破边界，先按迭代规则开新设计版本。

## 迭代规则

后续遇到实验问题时，新增版本文件，例如：

```text
design-v2.1.md
design-v3.0.md
```

每次迭代记录：

1. 触发问题或新证据；
2. 原设计的失效位置；
3. 修改内容；
4. 对创新性、任务定义和实验可比性的影响；
5. 是否需要重新核对相关工作。

不要直接覆盖旧版本。重大方向变化使用主版本号，局部调整使用次版本号。
