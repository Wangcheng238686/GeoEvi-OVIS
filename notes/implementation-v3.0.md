# 实施文档 v3.0

日期：2026-09-05。对应 `design-v3.0.md`。状态更新（2026-09-28）：T1 条件完成；
T2 修复版开发参数暂定 beta=0.5、delta=0、lambda=2，但原 sweep 漏做 B3；审计
补算显示 B3 高于 B2。下一步只允许在未暴露源图组做冻结配置验证，不能进入 T3。
具体证据见 `project-explainer.md` 的 T2 第二轮审计。
目标：验证同位置的跨类别相对证据，优先得到可信的否定或肯定结论。
路线收敛（2026-09-29）：本文件只负责完成 v3 冻结验证和归档，不实现二维滑窗、
prompt propagation 或 SAM memory；后续实施入口为 `implementation-v4.0.md`。

## T0：锁定现状与修复实验基础

记录 Git HEAD、脏文件、数据/候选文件校验值、运行参数、完成图像清单和历史输出。
核对正在运行的实验，不自动终止或覆盖。旧 NWPU 结果标记存在实现疑点。
修复逐图特征缓存、IoU 键顺序、v2 去竞争时 CCR/R 的边残留；验证断点续跑不漏写
部分图像、不把有一行输出等同完成。每个故障需要最小回归例。
修复有 GT 无预测图的 AP=0；全量 COCO 指标与 per-image AP50 指标分开报告。
对每图写原子完成记录，空输出也算有效完成；错误图重试前不计完成。
验收：两张不同图片的特征不串用；直接/向量化 IoU 一致；全量清单和预测去重正确。

## T1：开发数据与作用空间诊断

检查 iSAID/SIOR 可用源图标识，按源图分组固定开发/验证划分，避免同源切片泄漏；
无法恢复源图关系时如实登记限制。使用固定 seed，在运行前写出划分 manifest。
登记 NWPU/SOTA/FAST 结果暴露情况；不得以 NWPU 选择 β/δ/λ。
源域无现成 SAM3 候选时先生成有预算上限的小规模候选集，明确训练标签只用于评估。
统计同位置跨类候选对数量、GT 同实例比例、错类比例、可纠正实例占比；计算理想
错类消歧的诊断上限。输出 `notes/reports/v3-feasibility.md`。
若上限很低或关键错误不是跨类混淆，停止进入 T2，回报证据与原因。

## T2：最小打分实现与对照

新增独立 v3 入口与配置，不替换旧消息传递接口。实现设计公式 B0/B1/B2/B3，
共同使用固定候选、原始分 NMS、同 crop 的所有类别文本分数。
初始几何约定：mask IoU=0.5，crop 边距为 bbox 宽高各 10%；均属待验证启发式。
开发搜索预算：β∈{0,0.25,0.5}，δ∈{0,0.05}，λ∈{0,1,2}。
先仅按 B1 开发 mAP 选择 β，再固定 β 比较 B2；B3 使用同一组参数。
平分时选更小 β/λ，全部结果留档，不扩大搜索而不登记。
开发集用于选择，独立源域验证划分用于判断能否继续；λ=0 必须逐候选等价 B1。
其他验收：无竞争时等价 B1；复制同类竞争候选不改变分数；置换候选顺序结果不变；
不改候选/mask；不读取 GT 参与打分；缓存键跨图无冲突；嵌套类案例单列。

## T3：冻结并执行确认实验

在测试前保存配置、开发结果、代码 SHA、权重 SHA、词表、候选与 split manifest。
统一导出候选 ID、b/u/v、竞争类别、语义差值、变体分数及分解字段，以便定位失败。
输出到独立 `v3` 路径；B 系列不得覆盖 v2 A 系列。
先检查 B2−B1 以及 B2−B3；运行范围由 T1 作用空间及 T2 验证信号决定。
COCO mAP 差值的 bootstrap 必须对图像配对重采样并重新汇总 COCO AP，重复抽到的
图像使用新 ID、复制其 GT 和预测；保留零预测图。每图 AP50 CI 仅作补充。

新 v3 的继续条件（拟定于本方案，执行前随划分/预算冻结）：测试集等权平均
B2−B1≥1 个 mAP 点、B2−B0>0，且对应平均 mAP 配对 95% CI 下界>0；逐集结果
全部公开，任一集退化超过1点则不直接升级学习化。B2 不优于 B3 时不得归因于
空间关系。此条件独立于旧 v2 M2，不能用于把旧失败改判通过。
失败时写负结论，停止学习化/exemplar；成功后才制定下一阶段，不能预先堆模块。
