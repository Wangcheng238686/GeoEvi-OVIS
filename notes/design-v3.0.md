## 1. 目标与改变的原因

主任务保持：遥感图像＋类别文字 → 每个独立实例的 mask、类别和置信度。
SAM3 提供候选；研究问题收敛为：**同一物体被多个类别重复解释时，同位置的相对
视觉语义证据能否改善类别排序，并且不损害原本正确的预测？**

v2 的 NWPU 评测记录 A1/A2 mAP=24.75/13.30，但跨图特征缓存、IoU 查表、消融
口径与评测缺陷尚待修复，因此不能当成图方法失败的干净证据。此前的工程审计
不能证明科研机制有效。新的设计动因还包括：尺度相近不足以证明真实性；相关重复
不能视为独立证据；场景相似不等于类别兼容；候选自洽不等于真正无漏检。

## 2. 保留与暂停

保留 SAM3 text-only、P0 候选池、COCO 实例评测、固定 mask、标准类内 mask NMS。
新方法只重排原有候选，不生成 mask、不新增类别预测、不跨类硬删除实例。
暂停尺度支持加分、概率或合并、场景/共现加分、两轮消息传递和风险分调制。
ECR/URD/CCR 仅保留诊断用途；self/GT exemplar、学习化、长期记忆均后置。
以独立机制的效果决定是否需要图；不以保留图结构为目标。

## 3. 最小机制：同位置、不同类别的相对证据

固定查询词表与 P0 原始 score≥0.05 候选池。先做所有实验共享的类内标准 NMS，
按原始 SAM3 分数排序，mask IoU≥0.5 抑制，固定保留集合。
候选 ID 必须包含数据集、图像、类别和实例；图像缓存限单图生命周期。

对每个保留候选 i，使用同一个带固定边距的 bbox crop，提取冻结 RemoteCLIP
特征。对这个 crop 分别计算查询类别 y_i 与竞争类别的文本余弦 z_i(y)。
独立证据是该 crop 与自身类别的相似度；相对证据必须在同一个 crop 上比较，
不能把两个不同裁剪的原始 SAM3 分数直接解释成可比较的类别概率。

竞争集合 C_i 仅来自其他类别、与 i 的 mask IoU≥0.5 的保留候选。使用直接邻接，
不以连通分量强制同一实例、不对传递链硬合并；同一竞争类别只计一次。
嵌套/包含类可能合法共存，是必须单列检查的失败情形，不预设重叠必然错类。
初版不叠加文本 top-K 筛选，避免把真实混淆类提前排除。

候选机制（待开发集验证，不能称为校准概率）：

```text
b_i = clip((raw_score_i − 0.05)/0.95, 0, 1)
u_i = (1−β) b_i + β (z_i(y_i)+1)/2
d_i = max(0, max_{y∈C_i} z_i(y) − z_i(y_i) − δ)；C_i为空时 d_i=0
v_i = u_i × exp(−λ d_i)
```

该机制只在同位置竞争类有更强视觉语义证据时降低当前类分数。无竞争或证据不足
时原样保留独立分数。全部候选及 mask 保持不变，不施加新的输出阈值。
β、δ、λ 是待冻结的开发参数，不能借“经验合理”宣称最优；λ=0 精确退化到独立
对照。若该惩罚不能在开发数据上改善错类排序，就停止此候选机制。

## 4. 能回答因果问题的对照

| 实验 | 分数 | 候选/mask/NMS |
|---|---|---|
| B0 | b_i（SAM3 单调归一） | 完全相同 |
| B1 | u_i（独立视觉语义打分） | 完全相同 |
| B2 | v_i（局部跨类别相对证据） | 完全相同 |
| B3 | 相同相对公式但竞争类别来自整图其他预测类别，不用重叠关系 | 完全相同 |

B2−B1 才衡量局部竞争机制增量；B1−B0 衡量加 CLIP 的增量；B2−B3 检查是否
需要空间关系。另记录固定种子的竞争关系打乱对照与 λ=0 等价性。
各实验共享 β 和独立特征，不允许通过不同阈值、合并方式或候选数量制造优势。
v2 A0/A1/A2 数字保留旧名称，不与新 B 系列混写。

## 5. 证据、风险与退出

第一道门：开发数据中存在足够多的“同位置多类预测”，且其中确有可纠正的错类。
只用 GT 做离线错误类型、重叠图纯度、可修复上限分析；GT 不进入推理或竞争选择。
若主要问题是背景误检、无候选漏检或 CLIP 不能分辨细粒度类，则本机制的作用空间
有限，应报告上限并停止扩展。

第二道门：固定候选后，B2 优于 B1，且能证明是错类下降而非选择性报例。
报告全量 COCO mAP/AP50、固定池覆盖召回、top-K 检索质量、逐类/尺寸损益，
并拆分背景误检与跨类混淆。相同候选/单调 B0 不应凭空改变覆盖上限。

暂不宣称新颖性或贡献数量。本方向接近类别对比打分与跨类抑制，需专门复核相关
工作；空间竞争若不能胜过 B3，就不能声称关系建模有独立价值。
完整性要另证与 GT 漏检的相关性，并对照候选数/平均分；之后才考虑作为贡献。
