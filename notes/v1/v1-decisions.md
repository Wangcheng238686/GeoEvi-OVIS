# 方向决定记录（只记用户明确拍板的事）

## 2026-09-01 · 研究方向确认
- **最终目标**：发论文 / 找创新点（投稿档位未定，"先做再说"）
- **核心设想**：把"图结构"作为 SAM2/SAM3 记忆库的组织方式——节点和边描述"哪些记忆
  彼此有关"，在图上完成记忆的筛选、聚合、更新、压缩、检索
- **叠加要素**：多模态大模型(MLLM)语义记忆 + 不确定性/生成式方法
- **应用场景**：单帧遥感影像开放词汇实例分割；文本类别名 prompt 优先（用户知悉 SAM3
  训练用 short noun phrase，存在类名长度疑问待查），visual exemplar 路线保留为备选
- **明确不是**：视频分割（记忆机制服务于单帧，"记忆"对象需重新定义）
- **算力**：4× 魔改 4090 48G（模块级训练、7B 级 MLLM LoRA 微调可行；全量预训练不可行）

## 2026-09-01 · 基座选择
- **SAM3 为首选基座**，SAM2 作机制对照与消融跳板
- 理由：① 开放词汇文本+exemplar 双通道原生支持 ② detector 单帧独立可用，tracker/记忆
  可插拔 ③ 记忆管理已是"带证据的筛选更新"，改造叙事顺 ④ Agent 模板适配 7B MLLM
- 风险对冲：保留 SAM2/class-agnostic 变体作消融；写作时与 SAM2Long/Multiplex 划清边界

## 2026-09-01 · 实施基座与分工（用户拍板）
- **C5-v2 为后续实现的基座**：用户已在 RSPrompter 系遥感 SAM2 实例分割代码库上完成部分工作
- **当前阶段禁碰代码**：方案收敛前不读/不改项目代码，只做调研与方案设计
- **实施外包**：方案收敛后，实施任务交给其他 agent，主代理不承担实施
- **开放点（收敛时必须明确）**：C5-v2 基于 SAM2，而调研建议"SAM3 首选基座"——届时需定：
  开放词汇走 SAM3 替换 / SAM2+外挂文本通道（RS2-SAM2 或 MPG-SAM2 模板） / 或砍掉开放词汇
  只做 class-agnostic 图记忆。此决定影响数据集选择与撞车边界。

## 2026-09-01 · 评测协议方案（暂定记录，待与实验安排一并确认）
- **主协议 = 复用 SCORE benchmark**：闭集训练（iSAID 15 类 / SIOR-DIOR 20 类）→ 开集跨
  数据集测试（NWPU-VHR-10/SOTA/FAST）→ 实例级 mAP（FreeSeg 式）；HF split
  （HuangShiqi008/SCORE）；引用注明协议来源
- **注意**：SCORE 无 checkpoint，受控对比需自行复训（单卡 L40S 级，4×48G 无压力）；
  部分 GT 为 SAM 伪标签，论文中标注各测试集 GT 来源
- **三层协议扩展（= 贡献点）**：① NWPU-Refer category 子集 + LaSeRS 多[SEG]子集 AP 化
  （多目标/表达式设定，SCORE 未覆盖）② 不确定性校准评测（ECE/risk-coverage，无人做过）
  ③ OVRSISBenchV2 分辨率分组+滑窗效率协议（大幅面场景）

## 2026-09-01 · 方案收敛 Round 1（用户拍板）
- **第一篇主贡献包**：图结构记忆（主体）+ MLLM 语义记忆 + 不确定性门控；
  exemplar 通道留第二篇
- **读出机制**：memory-as-prompt（子图检索→聚合为 prompt tokens 喂解码头，SAM-I2V 式）；
  实施阶段允许微调
- **基座**：先跑 SAM3 零样本基线（NWPU-Refer/LaSeRS/OVRSISBenchV2 协议）再定；
  期间设计工作按"基座无关"推进（图记忆设计与基座解耦，读出层适配两者）
- **记忆边界：商榷中**——用户质疑"单图滑窗记忆与 OmniSAM 撞 regime"；
  候选：A 单图内空间图 / B 跨图像语义库 / C 双层生命周期异构图（临时层+持久层，
  固化算子=实例→原型升华）；主代理推荐 C，等用户定

## 2026-09-01 · 方案收敛 Round 2（用户拍板）
