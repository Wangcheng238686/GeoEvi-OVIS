## 威胁排序（重排后）

### ① SCORE（ICCV 2025 Highlight，arXiv 2507.12857）— 实际重叠度：中（任务层高、方法层低）✅已查重
- **任务层重叠高**：占掉 OV-RSIS 任务名 + 跨数据集 benchmark（iSAID/SIOR→NWPU-VHR-10/
  SOTA/FAST）+ **实例级 mAP 协议**（FreeSeg 式）+ HF 数据 split，且是 Highlight。
  **我方不能再称"首次提出 OV-RSIS 任务"，必须表述为"继 SCORE 之后"**。
- **方法层重叠低（逐项确认全无）**：无记忆机制（纯单帧前馈，上下文即席计算即弃）；无图结构
  （场景上下文 = RAI 掩码膨胀池化单向量 + GCA [CLS] cross-attn 注入，Sec 3.4-3.5）；
  无 MLLM（只有冻结 CLIP 双塔）；无不确定性（in/out-vocab 硬 ensemble）。
- 基座是 FC-CLIP（ConvNeXt-CLIP + Mask2Former），**非 SAM 系**；单张 L40S 训练；512×512 小图。
- 引用策略：作为 OV-RSIS establishing work / 必引基线，定位"任务与 benchmark 来源"；
  差异化句式："SCORE 的上下文以即席池化向量注入、即用即弃，缺乏对上下文与记忆元素间
  关系的显式组织；我们以图结构统一记忆的筛选/聚合/更新/检索，并引入 MLLM 语义记忆与
  不确定性建模。"
- **机会（它暴露的空白）**：① FAST 37 细粒度类仅 ~13 mAP——细粒度类区分远未解决，正是图
  关系推理+exemplar 的用武之地 ② 自证 RS-CLIP 泛化弱于 general CLIP ③ 无 exemplar 通道、
  无不确定性校准、无大幅面推理（512² 训练）④ 无 checkpoint 发布；其 benchmark/代码
  （Apache-2.0，HuangShiqi128/SCORE）可直接当对照基线与评测底座，复现成本极低。

### ② GMN（ECCV 2020, GraphMemVOS）— 实际重叠度：中低 ✅已查重
- "memory as graph"首创属它（边构造又借自 AGNN ICCV 2019），必须引用
- 但其图退化：3–5 个帧级节点全连接（5节点饱和，Table 5）、无建边准则、无生命周期
  （每帧重采样+首帧重初始化伪装）、图只在单帧 K=4 步内存活、纯视觉、无不确定性
- 引用策略：双重角色 = 图记忆可行性的早期证据 + 结构红利缺席的反面教材
- 首创表述纪律：只能主张"首次用于开放词汇/单帧遥感 + 首次统一图上生命周期算子 +
  首次语义-情景异构记忆"，不能主张"首次记忆图化"

| SAMIX (CVPR'25) | 和它的 RL 选参考什么区别 | 它是自回归序列决策（链）；我们是图上消息传递+子图检索（拓扑感知）。其消融"学习式筛选≫启发式"可引为我们的论据 |

## 动机证据链（写 Introduction 用）

1. **空地确认**：RS2-SAM2（AAAI'26，遥感+SOTA）显式弃用 SAM2 记忆 → "单帧遥感场景下
   SAM2 记忆尚未被利用"有直接文献引证
2. **空位确认**：SAM3 §B 官方承认跨目标共享全局记忆是未来工作
3. **压缩必要性**：RMem deciphering 实验——记忆越长注意力越稀释（0.247→0.056），
   但它只会删帧丢信息 → 图上"合并+继承"是严格升级
4. **语义必要性**：SAM2Long 败因自述"过度依赖细粒度视觉细节、缺乏语义理解" → MLLM 语义节点
5. **结构收益条件**：GMN 失败分析——图必须买到注意力买不到的东西 → 我们的异构节点/
   类型化边/生命周期算子就是答案
6. **可行性**：SAMIX 在 4×4090 跑通"冻结SAM2+小模块"；SAM-I2V 证明 0.2% 训练成本路线；
   OmniSAM 可训参数 <26MB —— 全部落在 4×48G 预算内

## 设计红线（来自查重的避坑清单）
1. 不做"N节点全连接帧图"（GMN 退化形态）
2. write/merge/evict 必须做成显式算子并逐一消融（GMN 只消融了节点数和步数）
3. 节点粒度用实例/原型级，不用帧级（GMN 帧级带背景噪声，Cutie 已证粒度红利）
4. 论文必须有"图增益 vs 记忆条数"曲线（GMN 5 节点饱和 = 装饰品图）
5. 线性注意力/无结构压缩是反面基线（EfficientTAM 实测线性注意力掉 >10 J&F）
